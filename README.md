# Restaurant Website

A modern, responsive restaurant website built using HTML, CSS, and JavaScript. This project focuses on elegant design, interactive elements, and a smooth user experience across desktop and mobile devices.

## Live Demo

[View the Live Website](https://tejesh-codes.github.io/tejesh-restaurant-website/)

## Features

- Responsive design for mobile, tablet, and desktop
- Modern restaurant-themed user interface
- Interactive menu with category filters
- Food menu cards with prices
- Mobile navigation menu
- Image gallery with lightbox
- Customer testimonials slider
- Reservation form with client-side validation
- Smooth animations and scroll effects

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## How to Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Project Purpose

Created as a portfolio project to practise responsive web design, front-end development, and interactive website features.
